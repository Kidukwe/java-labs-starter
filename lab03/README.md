## Реализовано

- Подготовительная часть: интерфейс `DiscountPolicy`, реализации `NoDiscount` и `PercentDiscount`, обработчик `PriceCalculator`.
- Вариант «Инженерия систем ИИ»: интерфейс `NormalizationStrategy`, реализации `MinMaxNormalization` и `MeanCenteringNormalization`, обработчик `FeatureProcessor`.
- Обработчики получают реализацию через конструктор и хранят ссылку интерфейсного типа. Конкретный алгоритм не создаётся внутри обработчика и не выбирается проверками типа.

## Контракты и граничные случаи

- Отрицательная цена запрещена. Процент скидки должен быть конечным числом в диапазоне от 0 до 100 включительно.
- В конструкторы обработчиков нельзя передавать `null` вместо политики или стратегии.
- Нормализация принимает непустой массив конечных чисел. `null`, пустой массив, `NaN` и бесконечности отклоняются с `IllegalArgumentException`.
- Min-max вычисляет `(value - min) / (max - min)`. Для одинаковых значений, включая массив из одного элемента, возвращается массив нулей.
- Центрирование вычисляет `value - mean`, где `mean` — среднее арифметическое элементов входного вектора.
- Обе стратегии возвращают новый массив и не изменяют исходный.
- Обе стратегии работают за O(n) времени и используют O(n) дополнительной памяти.

## Ограничения

Для чрезвычайно больших конечных значений сумма при центрировании или разность `max - min` могут переполнить `double`. Устойчивость к такому переполнению текущей реализацией и тестами не обеспечивается.
