# Лабораторная работа 4: Контракты equals, hashCode и HashMap

Условие: [`assignments/lab04-hash-table.md`](../assignments/lab04-hash-table.md).

Из корня репозитория запустите:

```bash
./mvnw -pl lab04 test
```

Windows PowerShell: `.\\mvnw.cmd -pl lab04 test`.

Основной код размещайте в `src/main/java/edu/course/lab04/`, тесты — в `src/test/java/edu/course/lab04/`. В начале каждого Java-файла укажите `package edu.course.lab04;`.

Модуль независим от остальных лабораторных.

## Решение

- `Book` сравнивает книги только по ISBN; название не участвует в `equals` и `hashCode`.
- В варианте «Инженерия систем ИИ» `SampleId` — неизменяемый ключ из имени набора и номера наблюдения. Оба поля участвуют в `equals` и `hashCode`.
- `SampleRegistry` хранит `DataSample` во внутренней `HashMap` и делегирует ей добавление либо замену, поиск, удаление, проверку наличия и получение размера.
- Учебный изменяемый ключ используется только в тесте: после изменения номера `get` не находит запись по той же ссылке, хотя размер карты не изменился.

## Дополнительная часть

`ChainedHashTable` хранит пары `SampleId` и `DataSample` в 16 корзинах. Корзина вычисляется через `Math.floorMod`, чтобы отрицательный хеш тоже давал допустимый индекс. В каждой корзине записи образуют связанный список. При совпадении корзины таблица сравнивает ключи через `equals`: равный ключ заменяет значение, неравный создаёт отдельный узел.

Число корзин фиксированное, перераспределения нет. Поиск, вставка и удаление зависят от длины выбранной цепочки, в худшем случае занимают O(n). Ключ `null` отклоняется; значение `null` допускается, и его наличие можно проверить через `containsKey`.
